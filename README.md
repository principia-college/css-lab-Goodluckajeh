# cssLab Honda Website

## Description
In this project, we created a responsive webpage for the 2025 Honda CRF300L Rally. The project includes:

- A header section with a logo and navigation menu.
- A footer section with social media links and copyright information.
- Styling for various elements using CSS, including fixed positioning for the footer to keep it visible during scrolling.
- Integration of external CSS libraries like Normalize.css and Font Awesome for consistent styling and icons.

The project demonstrates the use of modern CSS techniques to create a visually appealing and user-friendly webpage.

We had no issues during the development of this project.
